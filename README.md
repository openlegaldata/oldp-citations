# Citations

Scholarly publications citing Open Legal Data.

Source: [Google scholar](https://scholar.google.de/scholar?cites=6060629850077307180&as_sdt=2005&sciodt=0,5&hl=en)

## Layout

- `bib/2024.bib`: the original Google Scholar export.
- `bib/<citekey>.bib`: one file per citation added since, keyed Google Scholar style (`<author><year><titleword>`).

Last checked: 2026-11-08, against [OpenAlex](https://api.openalex.org/works?filter=cites:W3029812858) and Semantic Scholar (`DOI:10.1145/3383583.3398616`), because Google Scholar blocks automated access.
